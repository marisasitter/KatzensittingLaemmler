Katzensitting Lämmler – Website

Die Website enthält 43 Bewertungsbilder. Zunächst werden drei Bewertungen angezeigt; über „Weitere Bewertungen anzeigen“ werden alle sichtbar.

Bewertungen:
Neue Bewertungen können über das Formular gesendet werden. Die Website zeigt öffentlich keinen Freigabe-Bereich. Für die interne Prüfung ist der vorhandene Freigabe-Bereich über die URL mit ?admin=1 erreichbar.

Hinweis: Diese Version speichert neue Bewertungen nur lokal im Browser (localStorage). Für echte Kundenübermittlungen von unterschiedlichen Geräten ist eine Server-/Datenbank-Anbindung erforderlich.

AGB:
Die beiden neu hochgeladenen AGB-Seiten sind ausschließlich als Bilder eingebunden und wurden inhaltlich nicht verändert.
